# State of Dev

## Week of 2026-10-12

The shared build system reached version 1.0. HotCorners did the same. Several applications then used the occasion to reveal why stable infrastructure still needs actual applications attached to it.

<!-- truncate -->

## Shipped Work

### Shared Engineering Infrastructure

[GitHub-ActionTemplates v1.0.0](https://github.com/The-Running-Dev/GitHub-ActionTemplates/releases/tag/v1.0.0) shipped on October 17. Its reusable documentation, Node, PowerShell, npm-package, .NET, container, and Pages workflows now have a public contract: inputs and outputs may be added within v1, but not removed or renamed.

The library also gained verification-gate generation, a cross-repository drift report, release helpers, container attestations, and fixes found by real consumers rather than ceremonial example projects. The final release suite reported 505 passing Pester tests. Twenty-four consumer repositories moved from `@v0` to `@v1` before the cutoff.

The organization-level `.github` repository now owns shared Claude review and mention workflows plus starter workflows for the common repository archetypes. CI is becoming infrastructure instead of folklore with indentation.

### HotCorners

HotCorners reached the first stable `v1.0.0` tag after preview 3. The release includes profiles, automatic foreground-application switching, per-display corners, accidental-activation protection, settings import/export, the tray application, and the updater path.

The week also removed more test timing from the wall clock. App dispatcher tests and eight SnapshotPublisher timing cases now use deterministic draining or a manual clock instead of waiting and hoping Windows notices. Manual verification was recorded separately for the behaviors that require a real desktop and human pointer.

The stable tag is confirmed. A GitHub Release object was not available at the cutoff, so external distribution beyond the tag is not claimed here.

### Platform And Adventures

Platform closed two serious game-edge defects:

- The forwarding client no longer shares one workload cookie jar across callers. Before the fix, a later caller could receive the first caller's session cookie. The regression is covered by the composed-host suite, which passed 50 of 50 tests.
- The edge no longer follows workload redirects itself. It returns the workload's 3xx response instead of silently changing a POST to a GET or fetching an external destination server-side.

Platform also made audit records schema-level append-only, documented the hosted game service and package-consumer path, and moved releases onto the shared .NET workflow.

Adventures adopted engine revision-based compare-and-swap persistence. A valid action after a rejected one no longer becomes a false conflict, and an actual race now reaches the caller as `409 concurrent_modification` instead of `503 storage_failure`. Local save deletion is conditional and no longer races a newer write.

Its runtime probes were also separated properly: `/livez` proves the process is alive without touching PostgreSQL; `/readyz` proves the dependency path within a two-second bound. Optional startup migration now runs under PostgreSQL's advisory lock. The full local server suite for that work passed 264 tests, and the direct and edge-served public API responses were proven byte-identical.

### Project Creation And AgentKit

Project creation moved out of workstation setup and into the new [SubZeroDev.GitHub](https://github.com/The-Running-Dev/SubZeroDev.GitHub) repository. `New-Project.ps1` now scaffolds, commits, creates, configures, and pushes a repository with the standard ruleset. The project and OpenTofu setup gained 100 passing Pester tests, although real toolchains and a live create-and-push remain unproven.

AgentKit stopped treating `/interview` as a parole hearing. It now asks only questions that can change behavior, scope, constraints, interfaces, or acceptance; a stated reason is sufficient; and the first request to draft or stop asking ends the interview. Separate fixes removed design-check false positives for MCP methods and HTTP routes and moved Node CI onto the shared library.

## Meaningful Progress

### GodComplex — Consequences

The content-epoch handover was reconciled against the implementation. Reachable predecessor migrations are now accepted, story-graph adoption refuses narrowed enum or integer values that no longer fit, and the long-horizon deserialize proof has an explicit 30-second bound. The full engine suite reported 2,349 passing tests across 119 files.

The remaining week was mostly architectural honesty: stale review-register entries were closed, session capture was specified to refuse every replay-incompatible session rather than one visible log shape, and the brief now distinguishes implemented/replay-tested engine kinds from actual product consumers.

Four later PRs remain open: durable branch/session-write corrections, path-search indexing, roadmap-status correction, and the plan for durable content epochs in Adventures. Those are progress under review, not completed work.

### Cleaner

Cleaner merged a design for Junk, Browser, and Registry tabs, expanding the registry plan from four categories to fifteen and folding in distribution, safety, and real-system proof. A red-team pass then found six defects in that merged design. [PR #21](https://github.com/The-Running-Dev/SubZeroDev.Cleaner/pull/21) corrects them and remains open.

The plan is therefore useful and not yet authoritative enough to implement. This is inconvenient mainly because the review system worked.

### GitService And Docker-BuildAgent

GitService reconciled design after S52–S66, removed the retired tracker mirror, added a repository README and deploy command, and moved review and CI to the shared organization workflows.

Docker-BuildAgent moved package publication toward keyless NuGet Trusted Publishing, with PowerShell Gallery retaining its environment-scoped secret. The merged release-setup work is substantive; two automated dependency updates remain open.

## Decisions

- GitHub-ActionTemplates `v1` is the stable public workflow contract. `v0` remains frozen at 0.8.4 and is reported as behind.
- Platform's edge is a narrow forwarder, not a shared browser: it stores no workload cookies and follows no workload redirects.
- Credential ownership and redirect-header behavior at the edge remain an explicit G3 decision rather than an accidental consequence of `HttpClient` defaults.
- Project scaffolding belongs with repository provisioning in SubZeroDev.GitHub. SubZeroDev.Workspace returns to being workstation setup.
- AgentKit interviews clarify the requested system. They do not require the user to prove that wanting it is morally justified.

## Open Items

- Adventures still exposes the difference between another player's session/save ID and a nonexistent one through `403` versus `404` ([#86](https://github.com/The-Running-Dev/SubZeroDev.Adventures/issues/86)).
- Cleaner PR #21 must land before the accidentally merged PR #20 design is treated as the implementation contract.
- GodComplex PRs [#602](https://github.com/The-Running-Dev/SubZeroDev.GameEngine/pull/602)–[#605](https://github.com/The-Running-Dev/SubZeroDev.GameEngine/pull/605) remain under review.
- SubZeroDev.GitHub still has six open starter/provisioning issues: buildable Node and current Python starters, pre-ship build proofs, shell-free command execution, honest support or refusal for four additional languages, and Graphify indexing.
- HotCorners still has one open virtual-time conversion PR. The `v1.0.0` tag exists, but a GitHub Release entry was unavailable when checked.
