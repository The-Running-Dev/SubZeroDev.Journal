# State of Dev

## Week of 2026-10-26

This week produced two new applications, two Game Engine releases, a completed durable-content program, a portable conversation workflow, and a measured decision not to build a more fashionable retrieval stack.

The last item may be the rarest.

<!-- truncate -->

## Shipped Work

### BibleStudy

BibleStudy went from brief to a completed 18-slice first program. The merged sequence covers passwordless sign-in, reading and search, synchronized narration, groups, questions, reminders, private notes, offline installation and content, safe synchronization, export, small-phone layouts, and handover. The [S18 handover](https://github.com/The-Running-Dev/SubZeroDev.BibleStudy/pull/22) recorded 149 unit tests, 175 integration tests, and 77 end-to-end tests passing in their respective suites.

The application can also import the owner's CSB files. The verified import contained 1,189 chapters, 66 books, and 31,103 verse slots. The files remain outside Git and the image. The [import and deployment work](https://github.com/The-Running-Dev/SubZeroDev.BibleStudy/pull/24) explicitly leaves public-serving licence coverage unresolved, so this is shipped implementation, not a claim of an approved public CSB service.

### Dashboard

Dashboard completed its current program and reached a real owner-authenticated portfolio rollout. The installed snapshot contains 50 projects, 29 configured repository bindings, two prerequisite edges, 28 projects with fresh repository evidence, and 22 correctly reported as unavailable rather than guessed. Backup restoration reproduced all 20 public tables in a separate PostgreSQL volume, and the final immutable image was pulled and verified locally. [No VPS deployment was claimed](https://github.com/The-Running-Dev/SubZeroDev.Dashboard/pull/11).

Selected organization repositories now use the existing collector with explicit owner and repository validation. Unavailable selections fail closed and preserve the last published evidence. Apparently a dashboard can survive without converting absence into confidence.

### Game Engine And Adventures

Game Engine published [v0.12.0](https://github.com/The-Running-Dev/SubZeroDev.GameEngine/releases/tag/v0.12.0) on October 27 and [v0.13.0](https://github.com/The-Running-Dev/SubZeroDev.GameEngine/releases/tag/v0.13.0) on October 31. The 0.13.0 candidate recorded 2,461 engine tests, 26 release guards, 12 .NET tests, a reproducible 363-entry archive, and Adventures host evidence.

Across Game Engine and Adventures, Plan 54 is now executed: content epochs have durable identity, publications and hydration are epoch-aware, writes are fenced during change, permanent deletion is recorded, and an external ledger and reconciler retain the evidence. Adventures also made migrate-on-start the deployment default and retired the production one-shot migration container while preserving the expired-session sweep.

### AgentKit And MemoryKit

AgentKit added portable conversation fork, attach, return, reviewed MemoryKit extraction, and native Codex chat bridging with durable receipts and ambiguous-outcome recovery. It also introduced six task-specific model profiles from one shared policy and a read-only behavioral-pilot report that verifies evidence without quietly running or grading new trials. The latest merged AgentKit verification reported 588 passing tests, zero failures, and 20 platform or opt-in skips.

MemoryKit completed bounded lexical retrieval, native Claude and Codex recall hooks, optional evidence-based selection, and a guarded npm release workflow. The merged native-recall work reported 282 passing tests plus 9/9 Codex and 8/8 Claude acceptance cases. The package is still private and unpublished. Release engineering has learned to prepare without declaring victory, which is encouraging.

## Meaningful Progress

### WindowManager

WindowManager was designed as a 16-slice program and reached S4. It now has a themed desktop panel, separately built plugins, plugin crash isolation, and guardian-based recovery that restores the desktop work area after host death or a 30-second hang. The [S4 evidence](https://github.com/The-Running-Dev/SubZeroDev.WindowManager/pull/6) reports 58 core tests and 26 interactive end-to-end tests passing.

### Docker-BuildAgent

Docker-BuildAgent gained a host-side `build-agent build` launcher and composite GitHub Action, then added opt-in Docker-in-Docker for builds that need images, Compose, or Testcontainers without borrowing the host daemon. Docker-in-Docker requires an explicit flag and privileged execution. The action still depends on the 2.0 tool being published to NuGet, so the mechanism is merged but the distribution path is not complete.

### Repository Provisioning

SubZeroDev.GitHub added tested C#, Rust, Java, and Go starters; removed the unsupported Python option; stopped invoking project commands through a shell; and can build the initial Graphify code map during scaffolding. Generated repositories now begin with more evidence and fewer future archaeology projects.

## Decisions

- MemoryKit measured local embeddings and a cross-encoder reranker against lexical retrieval. Both quality gates failed. S19 and S20 were retired unbuilt, lexical retrieval remains the default, and vector or hybrid work now requires new evidence rather than optimism.
- Game Engine's Simulation and World Graph kinds now reject undeclared action parameters. Session capture design applies the same rule to retained history: acceptance is a declaration, not an invitation to send additional JSON and see what happens.
- Dashboard treats provider failure, partial discovery, stale evidence, and missing bindings as distinct states. It retains the last trustworthy snapshot and reports the failed attempt separately.
- MemoryKit's public package name, registry rights, and credentials remain owner decisions. The workflow refuses to publish until those facts exist.

## Open Items

- [MemoryKit PR #43](https://github.com/The-Running-Dev/SubZeroDev.MemoryKit/pull/43) remains open with portable storage plugins, managed Markdown plus Git, and bounded task discovery. Its 361-test result is branch evidence, not shipped state. Precision and no-answer abstention remain below target.
- MemoryKit is not published. Package identity approval, removal of `private: true`, registry authority, and post-publication verification are still required.
- BibleStudy still needs a licensing decision before the owner's CSB text can be served publicly. The repository has no GitHub release at this cutoff.
- Game Engine has designed `unknown_target` validation and `captureSession`, but [the implementation is still pending](https://github.com/The-Running-Dev/SubZeroDev.GameEngine/pull/621).
- AgentKit issues [#503](https://github.com/The-Running-Dev/SubZeroDev.AgentKit/issues/503) and [#505](https://github.com/The-Running-Dev/SubZeroDev.AgentKit/issues/505) retain model-cache validation and profile follow-ups. Platform [#356](https://github.com/The-Running-Dev/SubZeroDev.Platform/issues/356) still needs an outside .NET consumer to exercise migrations.
